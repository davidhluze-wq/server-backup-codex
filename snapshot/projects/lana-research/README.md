# LANA Research Dashboard

LANA is a research and paper-trading dashboard. It combines a PostgreSQL knowledge base,
research automation, strategy review, risk controls, and a browser interface on port 8811.

Use [`docs/ACTIVATE_ON_VPS.md`](docs/ACTIVATE_ON_VPS.md) for a clean installation on another VPS.
The repository snapshot intentionally excludes credentials, authentication data, logs, and live
research or trading records.
