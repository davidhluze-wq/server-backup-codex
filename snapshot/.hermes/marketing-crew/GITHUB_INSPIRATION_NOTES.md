# GitHub inspiration notes for Hermes Marketing Crew

These notes summarize public agent workflow patterns that were folded into the local Hermes marketing auditor setup.

## Patterns adopted

1. Iterative research loop
   - Generate initial queries.
   - Research public sources.
   - Reflect on knowledge gaps.
   - Run follow-up search when needed.
   - Finalize only after the evidence is sufficient.

2. Evidence labels
   - Mark claims as directly observed, inferred or missing.
   - Do not hide uncertainty.
   - Do not fill missing private data with invented numbers.

3. Specialist roles plus manager synthesis
   - Website/QA, SEO/content, competitor/market and messaging/conversion agents work in parallel.
   - Strategy synthesizer merges outputs and corrects contradictions.
   - Quality reviewer checks hallucinations, missing checks and client readability.

4. Client-first report output
   - Internal report can be detailed.
   - Client report must be short, visual and practical.
   - Client report still needs SEO, market comparison and product clarity, but in non-technical language.

## Applied to this auditor

- Added mandatory SEO coverage.
- Added mandatory regional competitor comparison.
- Added product/service clarity checks.
- Added factual error checks for contacts, CTA, offer, region and references.
- Added second-pass quality review checklist.
- Updated Drive export/index behavior for client-named final files.
