## Krátká CVE/advisory rešerše za posledních 7 dní

Zaměřeno na reálně viditelný stack: Ubuntu 22.04, Linux kernel 5.15, OpenSSH, systemd/snapd služby a Python dashboard. Na hostu nejsou podle faktů vidět nginx/apache/databáze/docker jako běžící veřejné služby; `containerd` balík se ve výpisu verzí neprokázal.

- **Ubuntu Security Notices – obecně:** aktuální přehled Ubuntu Security Notices zobrazuje nové položky z konce června 2026 včetně oprav pro různé balíky. Lokální `apt` ale v dnešních faktech nehlásí žádné čekající aktualizace, takže není vidět neaplikovaná oprava z Ubuntu repozitářů.
- **OpenSSH – CVE-2026-3497:** NVD uvádí zranitelnost v OpenSSH GSSAPI delta v některých linuxových distribucích; OpenCVE ji popisuje jako možný únik informací nebo DoS kvůli neinicializovaným proměnným. Výsledek Ubuntu vyhledávání ukazuje stav pro Ubuntu 26.04, ne jasný dopad na tento host s Ubuntu 22.04. Dnešní lokální fakta bohužel nezachytila přesnou verzi balíku `openssh-server`, ale `apt` nehlásí čekající opravy.
- **OpenSSH – USN-8222-1:** Ubuntu má dubnový USN pro OpenSSH zranitelnosti. Není to novinka posledních 7 dní, ale je relevantní pro vystavené SSH; vzhledem k nulovým čekajícím aktualizacím nepůsobí jako aktuální neopravený nález.
- **containerd – USN-8472-1 / USN-8471-1:** Ubuntu vydalo 25. 6. 2026 opravy několika zranitelností v containerd. Na hostu není Docker/containerd vidět mezi běžícími službami a výpis balíků neprokázal instalovaný `containerd`, proto jen informativně.
- **Linux kernel / CVE-2026-31431:** výsledky zmiňují high-priority kernel zranitelnost „Copy Fail“ s možností lokální eskalace práv nebo úniku z kontejneru. Host běží Ubuntu kernel `5.15.0-185-generic`, restart není vyžadován a `apt` nehlásí čekající kernel update.
