- **Ubuntu / PostgreSQL – USN-8294-1:** vyhledání Ubuntu Security Notices ukazuje PostgreSQL notice s balíkem pro Jammy `postgresql-14 – 14.23-0ubuntu0.22.04.1`. Host má právě `postgresql-14 14.23-0ubuntu0.22.04.1`, kandidát je shodný a služba poslouchá pouze lokálně; z lokálních dat nevyplývá čekající PostgreSQL oprava.
- **Ubuntu / Linux kernel:** vyhledání Ubuntu kernel notices ukazuje starší Jammy kernel notices včetně USN-8159-1 a USN-8388-1. Host běží na `linux-image-5.15.0-185-generic` verze `5.15.0-185.195`, kandidát je shodný a `reboot-required=no`; není vidět čekající kernel update.
- **OpenSSH – NVD CVE-2026-3497:** NVD výsledek popisuje problém v distribučních GSSAPI patchích okolo OpenSSH, ne nutně v upstream OpenSSH. Host má Ubuntu balík `openssh-server 1:8.9p1-3ubuntu0.15`, kandidát je shodný v `jammy-updates` i `jammy-security`; lokálně tedy není vidět neaplikovaná OpenSSH oprava.
- **OpenSSH – starší regreSSHion CVE-2024-6387 / USN-6859-1:** vyhledávání ji stále vrací, ale jde o starší položku z roku 2024; aktuální Jammy kandidát OpenSSH je shodný s instalovaným stavem.
- **Python/FastAPI/uvicorn – OSV:** obecné OSV hledání vrací několik historických záznamů pro FastAPI/uvicorn ekosystém, ale fakta neobsahují konkrétní dependency lockfile ani verze aplikačních balíčků. Bez seznamu závislostí nelze spolehlivě mapovat CVE na veřejně poslouchající Python služby.
- **Node.js:** lokálně je nainstalován distribuční `nodejs 12.22.9~dfsg-1ubuntu3.6`; APT kandidát je shodný. Node proces ve facts je jen lokální language server, ne veřejná služba.

## Doporučené následné ověření bez změn systému

1. Ověřit, zda dnešní cleartext údaj z procesní řádky nebyl zapsán i do dalších logů/historie, a následně zvážit jeho rotaci běžným bezpečným postupem.
2. Doložit stav firewallu způsobem, který read-only audit zvládne bez interaktivního root přístupu.
3. Ověřit efektivní hodnotu SSH `PermitRootLogin` a záměrnost root přihlášení z veřejné IP.
4. Potvrdit, že veřejné Python/web služby na portech `8811`, `8808` a `8765` jsou záměrně vystavené a chráněné autentizací nebo jiným řízením přístupu.
5. Doložit existenci obnovitelných záloh důležitých dat a konfigurací mimo samotné `/var/backups`.
